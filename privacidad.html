2. A quién aplica y qué datos tratamos

Esta política aplica al sistema administrativo de Restaurante Mateus para computador y, cuando corresponda, a sus servicios web relacionados. El sistema se utiliza para administrar pedidos, ventas, producción, caja, inventario y tareas del restaurante. Según la información que se registre, puede tratar:

  • Datos de clientes: nombre, documento, teléfono o correo cuando se proporcionan para identificar un pedido, elaborar una factura o atender una solicitud. Algunos de estos datos son opcionales.
  • Datos de pedidos y operación: productos, cantidades, valores, mesa o referencia del pedido, notas, método de pago, fechas, facturas, cierres de caja, gastos e inventario.
  • Datos del personal: nombre, teléfono, turnos y demás datos que el administrador decida registrar en los módulos de personal y operación.
  • Datos de acceso y funcionamiento: nombre de usuario o perfil, estado de sincronización, cambios pendientes, registros técnicos necesarios para mantener la aplicación y copias locales de la base de datos.

El sistema no está destinado a recopilar datos sensibles ni datos de niños, niñas o adolescentes. Por favor, no registre información de salud, datos biométricos u otra información sensible en notas o campos libres. Si un caso de atención requiere tratar datos de menores o sensibles, el responsable debe verificar previamente la autorización y las condiciones legales aplicables.

3. Para qué usamos los datos

Los datos se usan para:

  • Registrar y gestionar pedidos, productos, producción, ventas, pagos, facturación y atención de solicitudes del cliente.
  • Administrar inventario, recetas, gastos, turnos, personal, cierres y reportes internos del restaurante.
  • Guardar la información de forma local, realizar copias de respaldo y sincronizar los cambios con la base de datos en la nube cuando el computador tenga conexión a internet.
  • Controlar el acceso al sistema, mantener su funcionamiento y atender incidentes o solicitudes relacionadas con los datos.
  • Cumplir obligaciones contables, tributarias, comerciales y demás obligaciones legales aplicables.

Los datos no se venden ni se usan para enviar publicidad ajena a la operación del restaurante.

4. Cómo se almacenan y sincronizan

La aplicación de escritorio puede trabajar sin internet. En ese modo conserva los registros y cambios en una base de datos local del computador y genera copias de respaldo locales. Cuando hay conexión, los cambios pendientes se sincronizan con Supabase, proveedor de la base de datos en la nube. Los archivos que se carguen desde la aplicación también pueden guardarse localmente y sincronizarse con ese servicio.

Por esta razón, los datos pueden existir tanto en el computador del restaurante como en la nube. Una copia local no sustituye la sincronización; el administrador debe revisar el estado de sincronización y conectar el equipo periódicamente para enviar los cambios pendientes. La ubicación configurada para el proyecto Supabase es [CONFIRMAR PAÍS O REGIÓN DEL PROYECTO]. Si el proveedor trata datos fuera de Colombia, el responsable deberá informar el país y asegurar que el tratamiento cumpla las reglas colombianas sobre transmisión o transferencia internacional de datos.

El acceso local depende del control del computador, sus cuentas y credenciales. El responsable debe limitar el acceso al personal autorizado y proteger el equipo y las copias locales. Los proveedores tecnológicos aplican sus propias condiciones y políticas para prestar sus servicios.

5. Proveedores y comunicación de datos

Para prestar las funciones descritas, el sistema puede comunicar datos a Supabase para almacenamiento y sincronización. La versión web pública puede utilizar un proveedor de alojamiento y servicios técnicos para entregar la página y sus recursos. Estos proveedores deben tratar la información conforme a sus funciones y a los acuerdos o condiciones aplicables. El responsable no comunica datos a terceros para que los usen con fines publicitarios propios.

6. Tiempo de conservación

Conservamos la información durante el tiempo necesario para cumplir las finalidades descritas y las obligaciones legales, contables y tributarias del restaurante. Los documentos y datos sujetos a períodos legales de conservación se mantendrán durante el plazo aplicable. Cuando ya no sean necesarios y no exista una obligación que exija conservarlos, se eliminarán o anonimizarán de acuerdo con los procedimientos disponibles. Las copias locales y las copias en la nube pueden requerir procesos de eliminación separados.

7. Derechos de los titulares

De acuerdo con la legislación colombiana, el titular puede conocer, actualizar y rectificar sus datos; solicitar prueba de la autorización cuando sea exigible; preguntar por el uso dado a sus datos; presentar consultas o reclamos; solicitar la revocatoria de la autorización o la supresión del dato cuando proceda; y acceder gratuitamente a los datos objeto de tratamiento. También puede acudir ante la Superintendencia de Industria y Comercio (SIC) después de presentar la consulta o reclamo ante el responsable, en los casos previstos por la ley.

Para ejercer estos derechos, escriba al correo indicado en la sección 1 con el asunto “Protección de datos personales”. Describa el derecho que desea ejercer, identifique los datos o la relación con el restaurante y adjunte la información necesaria para verificar su identidad o representación. El responsable responderá dentro de los términos legales. No envíe contraseñas ni datos financieros sensibles en la solicitud.

8. Autorización y deberes de quien registra datos

Cuando la ley lo requiera, Restaurante Mateus solicitará autorización previa e informada para tratar datos personales y conservará evidencia de ella. Si el personal del restaurante ingresa datos de clientes o trabajadores, debe informarles el tratamiento y registrar solo la información necesaria para el servicio o las obligaciones del negocio. El titular puede abstenerse de entregar datos opcionales; en ese caso, algunas funciones que los necesiten —por ejemplo, emitir una factura con datos del comprador— podrían no estar disponibles.

9. Cambios a esta política

Podemos actualizar esta política para reflejar cambios en el sistema, en las finalidades o en las obligaciones aplicables. Publicaremos la versión vigente en esta página e indicaremos su fecha de actualización. Si un cambio requiere una nueva autorización, se solicitará antes de continuar el tratamiento correspondiente.

10. Normativa y autoridad

Esta política se interpreta conforme a la Ley 1581 de 2012 y sus normas reglamentarias, incluido el Decreto 1074 de 2015. La autoridad colombiana de protección de datos personales es la Superintendencia de Industria y Comercio: sic.gov.co.

Texto oficial de consulta: Ley 1581 de 2012 y Decreto 1377 de 2013.
